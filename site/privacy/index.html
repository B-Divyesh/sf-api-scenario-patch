Plain-language policy · effective August 28, 2026

Privacy

API Scenario Patch is local-first software. The CLI does not send telemetry, crash reports, captured requests, configuration, or generated patches to us.

The website

This static website does not use analytics, cookies, fingerprinting, accounts, forms, or third-party scripts. Its interactive demo runs entirely in your browser and stores nothing. A service worker may cache public site files on your device so the documentation works offline; clearing site data removes that cache.

The CLI

The proxy forwards traffic only to the upstream that you configure. Capture data stays in memory until shutdown, then the CLI writes the two paths you requested. Sensitive headers are always excluded. Bodies are excluded unless their route is explicitly allowlisted.

Your control

You control the configuration and generated files. Review patches before committing them. Because there is no API Scenario Patch service or account, we do not possess data to export or delete.

Contact

Open a repository issue for privacy questions. Policy changes will be recorded in Git.
