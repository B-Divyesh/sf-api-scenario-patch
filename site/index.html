Capture rules

What asp records by default

It records no request or response body until you allow a route. JSON field rules mask values before files are written.

  • 01Local-only listenerThe proxy accepts loopback addresses only.

Three steps

Create a scenario patch in three steps

  1. 1

    Set capture rules

    Run asp init. Choose routes, JSON fields to mask, and saved response values.

  2. 2

    Record your API flow

    Send existing client traffic through the local proxy. Keep using your usual API client.

  3. 3

    Commit the scenario patch

    Review the Markdown and YAML files with the pull request.
